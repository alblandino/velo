    Velo

    Un almacén clave-valor en memoria inspirado en Redis, escrito desde cero en Node.js puro.

    $ git clone https://github.com/alblandino/velo.git
$ cd velo
$ node bin/velo.js server
    Empezar Ver en GitHub

    Node.js 13 o superior · Cero dependencias · Licencia MIT

    Continuar donde lo dejaste:

    • Protocolo RESP Habla el protocolo de Redis sobre TCP y entiende también comandos inline, desde nc o telnet.
    • 23 comandos Strings, caducidad y servidor: de SET y GET a GETEX, KEYS y SELECT.
    • Expiración de claves Borrado perezoso al acceder y un barrido periódico para las claves que nadie vuelve a leer.
    • Clean Architecture Dominio, aplicación e infraestructura, con un comando por archivo y cero dependencias.
